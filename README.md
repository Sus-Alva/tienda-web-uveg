# Tienda Online - Reto UVEG

## Descripción
Aplicación web desarrollada como tienda virtual (e-commerce básico) para el módulo de la UVEG. Permite visualizar productos tecnológicos, precios y simular un carrito de compras.

## Proceso de Realización
1. **Preparación y Estructura:** Se organizaron los archivos de forma modular en carpetas (`/css`, `/img`).
2. **Optimización:** Se minificó el archivo CSS (`styles.min.css`) y se optimizó el peso de las imágenes para garantizar un rendimiento óptimo.
3. **Despliegue:** Se configuró un entorno de servidor web simulado localmente mediante Apache/Nginx.
